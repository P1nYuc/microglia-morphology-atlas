# Microglia Morphology Guide（微膠細胞形態指南）

本指南以繁體中文介紹 microglia 的形態特徵與生理功能，並說明相關研究的判讀限制，供生醫領域初學者查閱。

[瀏覽網站](https://p1nyuc.github.io/microglia-morphology-atlas/)

目前收錄：

- [分枝型微膠細胞（Ramified Microglia）](https://p1nyuc.github.io/microglia-morphology-atlas/pages/ramified-microglia.html)
- [阿米巴型微膠細胞（Amoeboid Microglia）](https://p1nyuc.github.io/microglia-morphology-atlas/pages/amoeboid-microglia.html)

各主題附有學術文獻，說明哪些結論可由形態觀察支持，哪些仍需功能實驗驗證。網站以 HTML 與共用 CSS 建置，使用深藍、青綠與白色，版面保持簡潔。
