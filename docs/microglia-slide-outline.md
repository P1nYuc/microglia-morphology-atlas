# 教學簡報大綱與審查

## 單次 Prompt 試跑

> 讀取 Wiki 索引及四個概念條目，規劃七張給初學者的 HTML 投影片。每張用一句話描述內容並附 Wiki 條目。

單次草案依序安排開場提問、比較外形、說明突起接近受傷處、發育期阿米巴型、用三維影像判斷材料位置、判讀假想圖片，以及整理三個讀圖問題。依序使用 [形態](../wiki/shape.md)、形態、[動態](../wiki/dynamics.md)、[情境](../wiki/context.md)、[吞噬](../wiki/engulfment.md)、情境與吞噬、綜合。

## 大綱審查與修訂

回讀來源筆記後，補上第 3–5 張欠缺的腦區、時間窗、胞體反應或胞內證據。採用現有網站樣式，保留繁體中文、文字比較卡與可展開解答。
