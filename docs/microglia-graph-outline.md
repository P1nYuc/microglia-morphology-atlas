# 文獻覆蓋率、證據卡與待確認大綱

## 文獻覆蓋率

| 教學問題 | 對應證據 | 本輪判定 |
| --- | --- | --- |
| 如何描述分枝型與阿米巴型？ | E02 的皮質形態描述、E03 的同日齡三維重建 | 通過。可描述代表外形，無法設定普遍的分類閾值。 |
| 影像如何顯示突起在動？ | E01 的基線時間序列與 E02 的損傷早期時間序列 | 通過。比較突起和胞體的行為，保留各研究條件。 |
| 圓鈍外形能判定發炎嗎？ | E03 的發育期白質例子 | 通過。可說明形態的判讀限制；此例沒有提供通用發炎判準。 |
| 什麼證據支持材料已吞入？ | E04 的包覆與電子顯微證據、E05 的逐層與胞內證據 | 通過。限於所觀察的目標與條件。 |

四個教學問題均有直接觀察或可界定限制的證據。五篇來源皆在大綱中有用途。排除跨物種推論、通用發炎診斷與以單張影像估算吞噬速率。

## 大綱草案，待使用者確認

| 張次 | 教學任務 | 使用證據 |
| --- | --- | --- |
| 1｜外形能告訴我們什麼 | 提出看圖判讀問題與學習目標 | 開場提問 |
| 2｜描述胞體和突起 | 並排描述兩種代表外形，提醒記錄成像條件和腦區 | E02、E03 |
| 3｜看突起的時間序列 | 對照基線伸縮與局部損傷早期反應 | E01、E02 |
| 4｜圓鈍外形與發育情境 | 以同日齡的兩個腦區說明判讀限制 | E03 |
| 5｜什麼證據支持吞入 | 比較海馬的包覆證據與視覺迴路的逐層、胞內證據 | E04、E05 |
| 6｜判讀假想影像 | 練習區分二維訊號重疊與胞內定位，再展開解答 | E03、E05 |
| 7｜三個讀圖問題 | 回顧外形、研究情境及待補證據 | 綜合 E01–E05 |

通過覆蓋率檢查後提出本草案，待使用者確認後進入逐頁稿。
