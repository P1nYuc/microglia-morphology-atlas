# 需求摘要

教學問題為「從外形能看出微膠細胞在做什麼嗎？」。讀者是初次接觸微膠細胞的生醫同學。完成後應能描述胞體與突起、解釋時間序列能支持的觀察，以及指出判定吞入所需的額外證據。

沿用網站、繁體中文、共用 CSS 與既有的七張簡報結構。以現有五篇原始研究為取材範圍，研究主張需能回查 Wiki 與證據位置，保留小鼠的腦區、日齡及成像條件。第六張保留假想情境與可展開解答。

先檢查證據覆蓋、整理證據卡，再由使用者確認大綱。確認後才寫逐頁稿。逐頁忠實度通過後才渲染 HTML，並各自保存檢查結果。交付包含 [AGENTS.md](../AGENTS.md)、[流程圖](workflow.md)、[執行報告](microglia-graph-check-report.md)、Wiki 與 HTML 簡報。
