## 目的與成果
建立能由 AI 持續擴充的微膠細胞型態與影像分析知識庫，對應作業要求。交付完整 AGENTS.md、首頁、一篇主題介紹頁，以及 README 中的本機瀏覽、GitHub Pages 發布與繳交說明。本次先完成本機專案；公開發布與 Repository 網址須在實際部署後填入，不能捏造。

## 實作方式
採用純 HTML 與共用 CSS，無需安裝套件或建置，適合直接部署到 GitHub Pages。相較框架或內容管理系統，此方式直接符合使用者指定的 index.html、css/、pages/、assets/ 結構，方便初學者維護。

## 頁面與視覺
繁體中文為主、搭配英文術語。白底、深藍文字、青綠重點色；以清晰字級、細線與留白呈現學術及醫療科技感。支援手機與桌面、鍵盤操作、可見焦點及跳至主要內容連結。

首頁：網站標題與介紹、主題目錄、知識庫範圍、使用方式及版權頁尾。只連結已建立的頁面。
主題頁：pages/ramified-microglia.html，包含網站標題、回首頁、形態特徵 / 核心概念、AI 影像分析挑戰與應用、參考資料及版權頁尾。說明形態不能單獨代表功能狀態，區分二維與三維分析，避免將 ramified 直接等同於不活化。任何示意圖均需標示非實驗影像。

## 維護規則
AGENTS.md 延續使用者提供的所有核心規則，補上來源引用、可及性、相對路徑、擴充範例、完成檢查及隱私注意事項。新增頁面時提供首頁 li/a 程式碼與插入位置；除非使用者要求同步修改首頁，依原 SOP 提供更新指引。本次建立首頁時納入主題頁連結。
